# Pokémon Champions Companion – Web v9.2.6

## Letzte Änderungen
- **Konto:** Passwortkriterien werden im Anmelde-/Registrierungsfenster unter „E-Mail speichern“ angezeigt (mindestens 8 Zeichen, Groß- und Kleinbuchstaben sowie Zahlen).
- **Schadensrechner:** Stahlpresse (Hard Press) skaliert die Basisstärke anhand der verbleibenden KP des Verteidigers (1–100).
- **KP-Eingabe:** Die Prozentangabe des Verteidigers wird direkt für Stahlpresse und die grafische Schadensanzeige verwendet.
