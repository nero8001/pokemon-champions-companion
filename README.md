# Pokémon Champions Companion

## Aktuelle Version: v7.7.14

### v7.7.14 – Deutsche Attackensuche im Team-Builder
- Verhindert, dass englische Fallback-Namen vor Abschluss des Übersetzungsladens dauerhaft zwischengespeichert werden.
- Leert den Attacken-Label-Cache nach dem Laden der Übersetzungen, damit Großklingenstoß zuverlässig über den deutschen Namen gesucht werden kann.

### v7.7.13 – Großklingenstoß ergänzt
- Espinodons Signatur-Attacke Großklingenstoß wird im Team-Builder ausdrücklich ergänzt, falls sie im externen Lernset fehlt.
- Die Ergänzung gilt für Espinodon und damit auch für Mega-Espinodon, das weiterhin das Attackenset der Basisform verwendet.

### v7.7.12 – Mega-Entwicklungen übernehmen Basis-Moveset
- Im Team-Builder beziehen alle Mega-Formen ihre Attackenauswahl direkt aus dem Moveset der Basisform.
- Die Mega-Form behält weiterhin ihre eigenen Statuswerte, Typen und Fähigkeit; nur die Attackenliste kommt von der Basisform.
