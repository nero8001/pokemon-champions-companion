# Pokémon Champions Companion

## Aktuelle Version: v7.7.10

### v7.7.10 – Team-Builder: Wesen aktualisiert Statuswerte sofort
- Beim Ändern des Wesens werden die angezeigten Lv.-50-Statuswerte direkt neu berechnet.
- Der bearbeitete Pokémon-Slot bleibt geöffnet.
- Die ausgewählte Wesen-Einstellung bleibt im Teamzustand erhalten und wird beim Speichern mitgesichert.

### v7.7.9 – Attacken per Checkbox auswählen
- Vor jedem der vier Attacken-Suchfelder gibt es eine Checkbox zur Auswahl der Kalkulationsattacke.
- Es kann immer nur eine Attacke ausgewählt sein; die vorherige Auswahl wird automatisch aufgehoben.
- Standardmäßig ist Attacke 1 ausgewählt.

### v7.7.8 – Meteorologe und Wetter
- Meteorologe wird anhand des ausgewählten Wetters korrekt als Feuer-, Wasser-, Gesteins- oder Eis-Attacke behandelt.

Die Schadensberechnung kann bei nicht vollständig verifizierten Spezialfällen weiterhin vorläufig sein.
